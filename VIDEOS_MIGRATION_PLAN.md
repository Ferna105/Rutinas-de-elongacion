## 4. Próximos pasos (en orden)

### 4.1. Instalar reproductor de video
La app hoy renderiza `.gif` con `<Image source={...} />`. Los archivos nuevos son `.mp4`, así que hay que:

1. Instalar **`react-native-video`**:
   ```bash
   npm install react-native-video
   cd ios && pod install && cd ..
   ```
2. Reemplazar el `<Image source={gif} />` por `<Video source={mp4} repeat muted resizeMode="cover" />` en los lugares donde se muestra el ejercicio en reproducción.
3. Conservar los posters PNG actuales (`src/assets/Ejercicios/posters/`) como thumbnail estático en las listas (no requiere video player); regenerar luego un primer frame de cada `.mp4` para los ejercicios renombrados.

Archivos a tocar (ya identificados por uso de `exerciseGifs`):
- `src/data/assets.ts` — cambiar `exerciseGifs` a `exerciseVideos`, claves apuntando a los `.mp4`.
- `src/data/types.ts` — renombrar campo `gifKey` → `videoKey` (o agregar nuevo y dejar deprecado).
- `src/data/database.ts` — actualizar nombres (`name`, `showableName`), descripciones (si correspondiera), y reemplazar `gifKey` por `videoKey` en cada `Exercise`.
- `src/features/routine/screens/StartRoutine.tsx`
- `src/features/routine/screens/RoutineInformation.tsx`
- `src/screens/app/Explore.tsx`
